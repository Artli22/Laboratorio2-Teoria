# Laboratorio2-Teoria

### El siguiente repositorio recopila los tres problemas del laboratorio en ramas diferentes, tal como solicita las instrucciones iniciales del documento.

#### Se decidio realizar los programas en Rust para seguir practicando el lenguaje para la clase de Graficas por computadora, por la rapida respuesta de la terminal al momento de correr el programa y porque el ambiente ya estaba disponible para su uso. 

#### Los videos de explicacion y prueba de funcionamiento de los programas se encuentran en el readme de su respectiva rama (Problema 2 & Problema 3). La investigacion previa del algoritmo de Shunting Yard se encuentra adjuntada en los archivos del programa del problema no.3 

#### Para finalizar los ejercicios escritos del problema no.1 se encuentran en el archivo PDF adjuntado en la rama main, desde el ejercicio A hasta el ejercicio H.
